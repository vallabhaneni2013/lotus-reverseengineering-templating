# Evidence Folder

Store evidence that supports the claims in the context library.

Examples:

| Folder | Purpose |
|---|---|
| `screenshots` | UAT/staging screenshots mapped to screens and capabilities |
| `interview-notes` | SME interview notes and validation decisions |
| `sql-samples` | Safe read-only SQL and result samples |
| `log-samples` | Sanitized runtime/job/API logs |
| `code-references` | File paths, class names, procedure names and snippets where allowed |

Do not store secrets, credentials, personal data or production-sensitive data unless approved and sanitized.
